額縁とは、世界を切り取り、価値を生む装置である

一般に額縁は「絵を飾るための木枠」と理解される。

しかし、それは額縁という存在のごく一部に過ぎない。

額縁とは本来、 何かを囲い、隔て、保護し、 「ここからが作品である」と宣言する装置である。

つまり額縁は物質ではなく、 境界をつくる機能である。
