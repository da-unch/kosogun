堀井 — Soft Ornament / 柔らかい装飾

額縁の装飾・角・テクスチャを、柔らかい素材そのものの物理的なふるまいで再解釈する試み。 硬い形をそのまま柔らかい素材でコピーするのではなく、額縁の形態原理を素材固有のふるまいへ翻訳することを目指す。

素材の2方向

  • ベロア／布：張力、ギャザー、スモッキング、余り、皺
  • スポンジ：圧力、圧縮、ふくらみ、くびれ、反発

Instagramリサーチ

The Metropolitan Museum of Art の Open Access 額縁画像をトリミングし、RGB Green(#00FF00) の焼き込みブレンドで 金色・歴史的な色味を切り離して凹凸・反復パターンとして観察している。

現在の投稿候補（R-H01〜R-H05）：

ID 額縁 観察
R-H01 Cassetta frame / Veneto / Late 18th century A vine-like repetition. 蔦のような反復。
R-H02 Cassetta frame / Florence / 1575–80 Countless dots and wave-like ridges. 無数のドットと波状の隆起。
R-H03 Rococo frame / British / ca. 1765 Ornament grows denser toward the corner. 角に向かって装飾の密度が高くなる。
R-H04 Reverse frame / Florence / 1600–1640 Vine-like forms project outward. 蔦のような形が外へ飛び出す。
R-H05 Cassetta frame / Veneto / Mid-16th century A scale-like surface. 鱗のような面。

今後広げたいカテゴリ：Profile/断面、Inner edge/内縁、Corner/角、Relief/起伏、Repetition/反復、Thickness/厚み、Deformation/変形。 目的は額縁史の網羅ではなく、布・スポンジで形状を作るための形態要素の採集。

スポンジ試作（進行中）

オレンジの3Dプリント部品（硬い骨格・支持体）と白いスポンジ（柔らかい装飾・外形）の二層構造で試作中。

主要な発見・仮説

  • 額縁性を作っているのは中央の穴の有無ではなく、写真の周囲を一周する明確な「内縁／境界」の存在ではないか （オレンジの内縁ありだと明確に額縁に見え、内縁なしでスポンジに直置きすると「柔らかい台座に置いた写真」に見えて額縁感が弱まる）
  • 今は額縁性をオレンジの硬いパーツが担いすぎている → その役割をスポンジ自身に移せないか検討したい
  • スポンジは「置く」より「圧力によって変形させる」方が重要（面/線/点で押す、二点でつまむ、スリット、前後から挟む、など未検証）
  • 正面より側面・断面（厚みの変化、折れ、くびれ、段差、圧縮）のほうが河﨑さんの断面研究と接続しやすく面白い

今後試したいこと

  • A. 内縁の柔材化：オレンジのリングを沈める／見えなくし、スポンジ自体が張り出して写真を囲う構造を試す
  • B. 写真を収める浅い凹み：完全な穴にせず、写真の厚み程度だけ凹ませ、「置いてある」→「収まっている」への変化を確認
  • C. 角から辺への連続性：角で太く辺に向かって細くなる連続形状。額縁の「角に向かって装飾密度が上がる」観察と接続
  • D. 断面パターンの再現：Cassetta / Reverse / Rococo の断面（凹凸・S字・段差）をスポンジの変形で作る
  • E. 反復パターンの翻訳：蔦・ドット・波・鱗を彫刻ではなく圧痕・縫い・局所圧縮・反復支持点に変換する

現状の問い

  1. どの形態要素があれば人はそれを「額縁」だと感じるのか
  2. 硬い額縁で彫刻・成形によって作られてきた形を、柔らかい素材ではどんな物理操作で作れるのか
